Проведи полный аудит безопасности этого проекта. ВАЖНО: встроенная команда
`/security-review` проверяет только текущий дифф — эта команда проверяет
**весь проект**. Запускать: перед первым прод-релизом, затем раз в месяц
или после крупных фич.

Режим: **только отчёт, ничего не менять**. Фиксы — отдельным шагом после
ревью отчёта пользователем, по одному, начиная с КРИТИЧНО.

## Шаги аудита

1. **Скоуп.** Прочитай `docs/integrations.md` (без секретов), выведи список
   всех Server Actions, API-роутов и форм (`grep -r "use server"`,
   `app/api/`, `submitLead`).

2. **Секреты.** Проверь: `.env*` в `.gitignore` и не в git-истории
   (`git log --all --diff-filter=A -- "*.env*"`); если установлен gitleaks —
   прогони `gitleaks git .`; `NEXT_PUBLIC_*` не содержат секретов; ключи
   не захардкожены в коде (`grep -rE "(sk-|ghp_|AKIA|ya29\.)" app/ lib/`);
   токены Telegram/CRM/Sheets используются только в серверном коде
   (не в `"use client"` файлах).

3. **Формы и Server Actions.** Для каждого экшена: Zod-схема валидирует
   на сервере (не только в клиенте); есть ограничение длины строк и формата
   телефона/email; Turnstile (или аналог) включён; есть rate limiting или
   защита от спама; JSON-fallback лидов пишется НЕ в `public/`; ПДн не
   попадают в `console.log`/логи PM2.

4. **Транспорт и заголовки.** В Caddy-конфиге (см. `docs/server-add-site.md`):
   HSTS, `X-Content-Type-Options: nosniff`, `X-Frame-Options` или CSP
   `frame-ancestors`. В коде нет `http://`-ссылок на внешние ресурсы.

5. **Зависимости.** `pnpm audit --prod` — перечисли critical/high с версией-фиксом.

6. **Утечки.** Sourcemaps выключены в проде; `robots.txt` не индексирует
   `/api`; `.env.example` содержит только плейсхолдеры; в MDX-контенте нет
   персональных данных, попавших случайно.

7. **CI/CD и VPS.** Версии GitHub Actions запинены (`@vX`/SHA, не `@main`);
   секреты только в GitHub Environment `production`; на VPS: ufw включён,
   SSH только по ключу, приложение под PM2 не от root (сверься с
   `scripts/bootstrap-vps.sh`).

8. **152-ФЗ (RU-сайты).** Cookie-баннер, чекбокс согласия на ПДн в каждой
   форме, страницы политики/оферты — по `docs/legal-templates.md`.

## Формат отчёта

По каждой находке: `КРИТИЧНО | ВАЖНО | РЕКОМЕНДАЦИЯ` + файл:строка +
описание в одно предложение + конкретный фикс. В конце — сводка одной
таблицей и предложение: какие находки занести в `.claude/memory/lessons.md`,
чтобы не повторять в следующих проектах.
