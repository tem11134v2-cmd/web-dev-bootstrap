# Pre-deploy чек-лист

Прогон перед **первым прод-релизом** каждого сайта и перед крупными
релизами (новые формы, платежи, смена домена). Быстрый способ: попроси
Claude «пройди docs/deploy-checklist.md и отметь каждый пункт ✅/❌/н-п
со ссылкой на доказательство».

Чек-лист — только индекс. Как чинить — по ссылкам на источники истины,
здесь ничего не дублируется.

## 1. Секреты и доступы

- [ ] `.env*` нет в git-истории; в репо только `.env.example` с плейсхолдерами
- [ ] Прод-секреты только в GitHub Environment `production` (`PROD_ENV_FILE`) — см. `CLAUDE.md § Automation rules`
- [ ] `NEXT_PUBLIC_*` переменные не содержат ключей/токенов
- [ ] Версии GitHub Actions запинены (`@vX` или SHA, не `@main`)
- [ ] `/security-audit` прогнан, КРИТИЧНО-находки закрыты

## 2. Формы и лиды

- [ ] Каждая форма: серверная Zod-валидация + Turnstile — см. `forms-and-crm.md`
- [ ] Тестовый лид прошёл во ВСЕ подключённые sink'и (Sheets / Telegram / CRM)
- [ ] JSON-fallback работает и пишет НЕ в `public/`
- [ ] Чекбокс согласия на ПДн в каждой форме — см. `legal-templates.md`

## 3. Транспорт и сервер

- [ ] HTTPS работает, сертификат выписан (Caddy ACME) — см. `server-add-site.md`
- [ ] Заголовки: HSTS, nosniff, frame-ancestors — конфиг в `server-add-site.md`
- [ ] `scripts/rollback.sh` проверен на этом сайте (сухой прогон): откат понятен
- [ ] PM2 процесс поднимается после `pm2 reload`, порт в реестре — см. `server-multisite.md`

## 4. Легальное (RU)

- [ ] Cookie-баннер показывается и пишет согласие — см. `legal-templates.md`
- [ ] Страницы «Политика обработки ПДн» и оферта опубликованы и слинкованы из футера

## 5. SEO

- [ ] `robots.txt` + `sitemap.xml` доступны; прод НЕ закрыт `noindex` — см. `seo.md`
- [ ] Мета title/description на всех страницах; Schema.org валидна
- [ ] Редиректы со старых URL работают (если миграция) — список в `pages.md`
- [ ] Сайт добавлен в Яндекс.Вебмастер и Search Console

## 6. Производительность и качество

- [ ] `pnpm build` зелёный; `pnpm lint` и `pnpm typecheck` без ошибок
- [ ] Lighthouse mobile + desktop ≥ 90 — методика в `performance.md`
- [ ] Проверка на 375/768/1280px, без ошибок в консоли браузера
- [ ] Реальный телефон: iPhone Safari (главный источник сюрпризов)

## 7. После деплоя (первые 24 часа)

- [ ] Тестовый лид с прода дошёл до заказчика
- [ ] Яндекс.Метрика/аналитика собирает визиты (ID — в `references.md`)
- [ ] `pm2 logs` без повторяющихся ошибок
