# AI-ассеты — фото и иллюстрации с заказчиком

Конвейер получения изображений, когда живых фото нет, а сток не хочется. Проверен боем (rustam): заказчик генерит по промтам Claude, вся серия консистентна по стилю.

## Конвейер

1. **Claude пишет фото-промты** в `docs/photo-prompts.md` — проектный файл, **коммитится в `docs/` как артефакт** (повторяемость, догенерация в том же стиле через месяц).
2. **Заказчик генерит** в своём инструменте (ChatGPT / Midjourney) и присылает файлы.
3. **Claude раскладывает** в `public/images/` (осмысленные имена: `hero-workshop.jpg`, не `IMG_0231.jpg`) и ужимает скриптом sharp — см. `docs/performance.md`.
4. **Итерации:** кадр не подошёл → правится сюжет кадра; Блок СТИЛЯ не трогаем, иначе серия развалится.

## Структура `docs/photo-prompts.md`

- **Блок СТИЛЯ** — единый префикс на всю серию: стиль съёмки, свет, палитра (согласована с дизайн-токенами из `docs/spec.md`), настроение, «камера». Вставляется перед каждым сюжетом без изменений — это и даёт консистентность.
- **Сюжет на кадр** — 1 промт = 1 изображение: что в кадре, ракурс, для какой секции (`hero главной`, `карточка услуги X`).

Пример:

```
## Блок СТИЛЯ (префикс каждого промта)
Реалистичная фотография, естественный дневной свет, тёплая палитра
(терракота/бежевый), лёгкая глубина резкости, 35mm, без постановочности.

## Кадр 1 — hero главной
{Блок СТИЛЯ}. Мастер в рабочих перчатках шлифует деревянную столешницу
в светлой мастерской, вид сбоку, руки в фокусе.
```

## Правила промтов

- **Без логотипов, текста и брендов в кадре** — генераторы рисуют нечитаемую кашу вместо букв, чужой бренд = юридический риск.
- **Реализм под нишу:** услуги/производство/стройка — фотореализм; IT/финансы — допустимы абстракции и 3D-иллюстрации. Стили в одной серии не смешивать.
- **Палитра консистентна** с токенами сайта — задаётся один раз в Блоке СТИЛЯ.
- **Люди — без крупных лиц «в лоб»** (AI-лица выдают генерацию): руки, спины, полуобороты, средние планы.

## Приёмка присланных файлов

Перед раскладкой в `public/images/` проверь каждый файл:

- **Размер:** hero ≥ 1920px по ширине, карточки ≥ 800px. Меньше — просить перегенерацию в большем разрешении, апскейл не делаем.
- **Ориентация под слот:** hero — горизонталь, карточки — под пропорции макета. Кроп — можно, растяжение — нет.
- **Стиль:** кадр из серии не выбивается (свет, палитра). Выбивается → перегенерация с тем же Блоком СТИЛЯ.
- **Артефакты:** лишние пальцы, кривой текст на заднем плане, «пластиковые» лица — брак.
- Формат хранения — jpg/png как прислали; WebP/AVIF на лету отдаёт `next/image`, вручную не конвертируем.

## Опция: генерация самим Claude

Если подключён image-MCP (например, `openrouter-image`) — Claude генерит сам по тем же промтам, без цикла с заказчиком. Промты всё равно пишутся в `docs/photo-prompts.md` ДО генерации — артефакт остаётся.
